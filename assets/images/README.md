# Fictional website demonstration imagery

These photographs were generated for the live website demonstration. They are sample imagery, not client work, real property listings, or photographs of the studio's projects.

- `website-proof-sheet.webp`: apartment, salon, seasonal food, timber house, office architecture and ceramic objects.
- `website-detail-sheet.webp`: additional home interiors, salon products, pantry products and ceramic objects.

Each sheet contains a 3 × 2 grid. CSS crops the appropriate photograph, so all previews share two cached local image requests. The source compositions were generated with OpenAI image generation and exported to WebP for the website. No external image service is required at runtime.
