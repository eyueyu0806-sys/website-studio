# Fictional website demonstration imagery

These photographs were generated for the live website demonstration. They are sample imagery, not client work, real property listings, or photographs of the studio's projects.

- `website-proof-sheet.webp`: apartment, salon, seasonal food, timber house, office architecture and ceramic objects.
- `website-detail-sheet.webp`: additional home interiors, salon products, pantry products and ceramic objects.

Each sheet contains a 3 × 2 grid. CSS crops the appropriate photograph, so all previews share two cached local image requests. The source compositions were generated with OpenAI image generation and exported to WebP for the website. No external image service is required at runtime.

## Actual GARAGE HOUSE NAVI screenshots

- `garagehouse-navi-desktop.webp`: 1440 × 900 desktop viewport.
- `garagehouse-navi-mobile.webp`: 390 × 844 mobile viewport.

Captured from https://garagehouse-navi.com/ on 2026-10-06, after loading the actual public HTML, scripts, fonts and images. Chromium rendered the unmodified responses fetched through curl with TLS verification, because Chromium did not trust the environment's proxy certificate. Both viewports returned HTTP 200 and rendered without JavaScript exceptions. The PNG captures were compressed to WebP without compositing or changing the design.

These are screenshots of the independently made/operated website, not commissioned client work. Photography inside the captured site retains that site's own “イメージ写真” label.
