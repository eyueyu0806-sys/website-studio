# 見積書・契約書の使い方

2026年10月7日版。公開中の標準料金・取引条件に合わせた、事業用の静的Webサイト制作の初期ひな形です。記入済みの契約書ではありません。取引の実態や追加条件に合わせて調整し、必要に応じて専門家へ確認してください。

## 書類

`pageatelier-business-documents.zip` に編集用の見積書・契約書・サポート申込書と、表示確認用PDF・この案内をまとめています。PDFは未記入の見本です。案件ごとの送付には、編集・確定した書類から改めてPDFを作成してください。

| ファイル | 用途 |
| --- | --- |
| `estimate-template.xlsx` | 見積書。「1ページ制作」「小規模サイト制作」のどちらか1シートを使用。税込総額・工程内訳・着手金・残金を計算。各シートは印刷2ページの想定。 |
| `website-production-contract.docx` | 制作契約書。本文、正式な当事者情報と署名欄、別紙1の仕様記入欄、別紙2の確定見積書添付欄。 |
| `optional-update-support.docx` | 月額サポートを希望する場合だけ使用する、別の申込書・合意書。 |
| `contract-clauses.md` | 制作契約の条項をテキストで確認するための資料。実際の締結にはWord版の当事者欄・別紙も確定。 |

Word・Excelで編集できます。Googleドライブを使う場合は、本人だけがアクセスできるフォルダへアップロードしてGoogleドキュメント・スプレッドシートで開き、変換後の数式・改ページ・日本語の表示を確認してください。公開リンク共有を有効にしないでください。

## 使う順番

1. このひな形をリポジトリの外にある非公開フォルダへコピーします。案件ごとに作業用のコピーを作り、原本の空欄ひな形を残します。
2. 見積書の該当シートに、見積番号・版・発行日・有効期限・相手の正式情報・案件名を記入します。乙側の正式氏名・正確な住所・連絡可能な電話番号・振込口座も記入します。サービス名だけを契約当事者名にしません。
3. ページ・セクションの名称と掲載量、素材、フォーム受信先・利用サービス、公開アカウント、追加機能、外部費用と負担者を確認します。プライバシーポリシーは原稿支給1ページを制作ページ数の外で掲載。その他の法務ページやCMS等は追加扱いを明記します。
4. Excelの税込単価・数量を確定します。追加がなければ数量0の追加行はそのままでも構いません。工程配分も実作業に合わせて確定します。最初の3工程の割合を編集すると、確認・公開の割合と金額は残りを自動計算します。合計金額・税額・工程内訳・50％ずつの支払額を確認します。追加料金のある作業は承諾前に実施しません。
5. 素材支給日・制作開始予定日・最終確認案日・公開予定日・着手金と残金の具体的な支払期限を記入します。2週間は必要条件が揃ってからの目安で、実際の日付を双方で合意します。
6. 契約書の甲・乙・正式情報・別紙1を記入し、見積番号・版・発行日・税込総額を見積書と一致させます。該当しない欄は「なし」とし、未記入欄は確定します。実績掲載は許可しないのが初期状態です。
7. 見積書の使用シートだけをPDFにし、確定版の契約書と一緒に送り、全文・別紙一式への双方の承諾を保存します。署名・電子署名、または同じ確定PDFと版を特定した明示的なメール承諾で進めます。見積書だけの送付や、曖昧な「了解」だけで着手しません。
8. 着手金を請求し、仕様確定・素材・入金が揃ったら開始日をメールで確認します。制作後は最終承認を記録し、残金確認後に公開・納品。ソース、更新案内、使用素材の条件、アカウントの引渡しを行います。
9. サポート希望があれば別の申込書を確定します。標準は暦月単位、月5,500円、月2回・合計60分。途中月開始等は料金・期間・回数・期限を個別欄で合意します。

書類の最上部にある「記入用ひな形」「未記入のまま使用しない」等の案内とフッターのひな形表記は、全項目を確定してから送付版で削除・版番号に差し替えます。Wordの［記入］やExcelの［ ］が残っていないか検索し、印刷プレビューも確認してください。

## 最初に採用した条件と、案件ごとに調整する初期案

公開条件に合わせた基本設定は、55,000円／110,000円、修正2回、銀行振込50％／50％、仕様・素材・着手金が揃ってから14日間目安、着手前の原則返金、着手後の実施分精算です。更新サポートは任意で別契約です。

書類用に具体化した初期案は、見積有効期限14日、完成案への回答5営業日、精算合意後の余剰金返金10営業日、公開後30日の初期不具合確認、工程配分「構成20％・デザイン30％・実装40％・確認公開10％」です。業務の実態に合わせて、相手に送る前に調整できます。回答がないだけで承認にはせず、30日で法令上の権利が消える条項にもしていません。

キャンセル精算は、確定した工程金額と実施割合・作業記録が根拠です。工程に少し入っただけで全額を請求したり、未実施分や未承諾の費用を請求したりしません。制作側の不履行は顧客都合のキャンセルと区別します。

新規成果物の権利は全額支払い・納品後に移転し、第三者の素材・フォント等は利用条件に従います。元からある汎用コード等は移転対象外ですが、顧客のサイト運営・改修に必要な利用を認めます。独占できない素材まで全権利を譲る約束にはしません。

## 非公開の保管

正式氏名・住所・電話番号・口座・顧客情報・署名入り書類・認証情報は、GitHubや公開サイトへ保存しません。非公開のフォルダへ保管し、送付先を確認して、案件関係者に限定して提供します。リポジトリ内の `business/private/` は誤追加防止のため無視設定にしていますが、基本はリポジトリ外で保管してください。

GitHubへ保存するのは、空欄のひな形とこの案内だけです。このフォルダはGitHub Pagesへ配信しません。`main` が公開リポジトリである場合、ひな形自体は他の人も閲覧できます。

領収書・請求書は見積書とは別です。適格請求書発行事業者の登録有無はこのひな形から分からないため、登録番号を作ったり、適格請求書を発行できると記載したりしていません。請求書を作るときは実際の登録・税務上の取扱いに合わせます。

## メール文例

件名：Webサイト制作の見積書・契約書のご確認（案件名／番号・版）

> このたびはご相談ありがとうございます。制作範囲・税込金額・納期・お支払い・キャンセル条件をまとめた見積書と制作契約書を添付します。契約書の別紙を含めてご確認いただき、修正したい点があればお知らせください。内容が確定しましたら、同じ確定版一式への承諾を確認して、着手金のご案内をお送りします。

メールで締結するときの承諾例：

> 添付の「契約書ファイル名」「見積書ファイル名」（案件番号、各版番号）及び別紙すべての内容を確認し、承諾します。契約当事者：正式名称・氏名／日付。

乙も同じ確定版を特定した承諾メールを返信し、双方のメールと添付PDFを保存します。

## ひな形の更新

`generate_templates.py` は空欄ひな形のみを生成します。実行には Python、`python-docx`、`openpyxl` が必要です。保存先はこのフォルダです。実際の個人情報・顧客情報をスクリプトに書かないでください。

公開条件を変更するときは、`PRICING.md`・`commerce.html`・`index.html` とひな形を揃えます。ひな形を変更しても、既に締結した契約を自動的に変更しません。
